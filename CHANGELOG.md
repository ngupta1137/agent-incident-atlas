# Changelog

All notable changes to the schema, taxonomy, and dataset are recorded here. Versions follow the pattern MAJOR.MINOR.PATCH. A change to a taxonomy definition or a schema field increments MINOR. Data additions and fixes increment PATCH. Each release is archived on Zenodo (see `RELEASING.md`).

## 0.1.0 (2026-10-21)

- First release.
- Schema version 0.1.0 with documented fields (`schema/incident.schema.json`, `schema/FIELDS.md`).
- Taxonomy version 0.1.0 with 14 governance failure types (`taxonomy.md`, `schema/taxonomy.json`).
- 20 illustrative composite seed records, all marked `"seed": true`, plus JSON and CSV exports.
- Two starter notebooks: failure-pattern frequency analysis and a postmortem template.
- Validation and export scripts, contribution guide, and continuous integration checks.
