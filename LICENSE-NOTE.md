# Which license covers what

This repository has two licenses. They do not overlap.

| What | License | File |
|---|---|---|
| The dataset: everything in `data/` | CC-BY-4.0 | `LICENSE` |
| The schema and taxonomy: everything in `schema/` and `taxonomy.md` | CC-BY-4.0 | `LICENSE` |
| Written documentation: `README.md`, `CONTRIBUTING.md`, `RELEASING.md`, `CHANGELOG.md`, and the prose and charts inside notebooks | CC-BY-4.0 | `LICENSE` |
| Code: `scripts/`, the code cells in `notebooks/`, and `.github/workflows/` | MIT | `LICENSE-CODE` |

If a file is not listed, use the folder it sits in. If you are unsure, ask in an issue.

## What this means for you

- **Using the data or taxonomy.** You may copy, adapt, and build on it, including commercially, as long as you give credit. Cite the Atlas using `CITATION.cff` or the section in `README.md`. If you adapt it, say what you changed.
- **Using the code.** You may use it in any way, including in closed-source work. Keep the MIT notice with any copies of the code.

## Contributions

By submitting an incident record you agree to license it under CC-BY-4.0. By submitting code you agree to license it under MIT. You also confirm that you have the right to share what you submit. See `CONTRIBUTING.md`.

## Seed records

The records marked `"seed": true` are illustrative composites written by the maintainer. They describe no real organization or event. They carry the same CC-BY-4.0 license as the rest of the data.
